# 资料契约

下列记录为确定性生成的本地合成资料，不含真实主体信息。不同文件通过标识字段关联，版本、生效时间、缺失状态和回执字段保留原始业务含义。

| 文件 | 字段 | 记录数 |
| --- | --- | ---: |
| `requests.csv` | `request_id`, `requester`, `department`, `question_text`, `region_scope`, `period_start`, `period_end`, `request_state` | 48 |
| `metric_catalog.csv` | `metric_id`, `metric_name`, `definition_version`, `grain`, `owner`, `valid_from`, `status` | 24 |
| `dataset_access.csv` | `dataset_id`, `region`, `sensitivity`, `purpose`, `requester_role`, `access_decision`, `policy_version` | 42 |
| `analysis_runs.csv` | `run_id`, `request_id`, `metric_id`, `dataset_id`, `data_version`, `coverage_state`, `analyst`, `delivered_at` | 54 |
| `actions.csv` | `action_id`, `run_id`, `business_owner`, `decision`, `accepted_at`, `due_at`, `completion_state`, `result_ref` | 60 |

数据缺失、待审、争议和未回执均表示状态未知或处理中，不能解释成零值或成功。记录中的模拟日期用于复现跨期关系，不表示真实业务发生。
